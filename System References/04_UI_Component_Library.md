# 04 — UI Component Library

> Components in `css/app.css` + markup generated by `js/features/*.js`. Dynamic values always via `esc()` (document 12).

## 4.1 Frame (`index.html`)

| Component | Class/ID | Notes |
|-----------|----------|-------|
| Shell | `#app-shell` | `max-width:30rem`, centered, frame shadow |
| Topbar | `#app-topbar`, `.tb-btn`, `#btn-back`, `#tb-title`, `#btn-lang`, `#btn-theme` | Sticky + blur; back hidden on main tabs |
| Tabbar | `#tabbar`, `.tab(.active)` | Floating dark pill; gold active dot |
| Screen stage | `#screen` | `screenIn` animation on every render |
| Toast | `#toast` | `role=status`, `hidden` by default |
| Debug | `#debug-fab`, `#debug-panel` | Only when `store.state.debug` |

## 4.3 Component Rules

1. New features **reuse** the above first; new classes only when nothing matches (and must use document-03 tokens).
2. User/API text always `esc()` — never build HTML with raw interpolation.
3. Every `data-action` must have an owner in `*Actions` (verified by the document-16 smoke test).
