# Atribusi Data Segmen Audio

Sumber segmen masa per kata:
- **Quranic Universal Library (QUL)** — https://qul.tarteel.ai (editor segmen, `surah_audio_files/7`)
- **Quran Foundation API v4** — https://api.quran.com (sumber muat turun teknikal, stabil & awam)
- Qari: **Mishari Rashid Al-Afasy (Murattal)**, `recitation_id=7`

Lesen data QUL: **CC-BY-4.0** (dengan atribusi seperti fail ini).

Audio MP3 (Fasa 4b): distrim dari CDN, **tidak** disimpan dalam repo ini.

Data digunakan untuk tujuan peribadi (pembelajaran Al-Quran).
Tidak untuk diedarkan semula atau dikomersialkan.
