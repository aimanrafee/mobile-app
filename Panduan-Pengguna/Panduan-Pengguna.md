# Panduan Pengguna — Taubat.App

> **Lapisan pengguna** (bukan dokumen pembangun). Juga tersedia dalam aplikasi: Lainnya → Panduan.
> Bahasa: aplikasi dwibahasa MY/EN — butang MY di bar atas untuk tukar.

## 1. Mula Pantas

1. Buka aplikasi — skrin **Utama** menunjukkan tarikh Masihi + Hijri dan kira detik solat seterusnya.
2. Ketik **Tepat / Lewat / Qada** untuk setiap waktu. Ketik semula untuk padam kesilapan.
3. Lihat **streak** (hari berturut), **minggu ini**, dan **heatmap 28 hari** sebagai motivasi lembut.
4. Buka **Panduan** ini semula bila-bila masa dari Lainnya → Panduan.

## 2. Setiap Ciri

| Ciri (tab) | Cara guna |
|------------|-----------|
| Utama | Pilih hari (±3 hari), tanda status solat; semasa haid, baris dikecualikan automatik |
| Quran | Cari surah → buka → baca MY/EN → tanda ayat ★ → sambung dari sepanduk |
| Iqra' | Pilih tahap 1–6 → ketik huruf dikuasai → % kemajuan; tandai semua / set semula |
| Zikir | Ketik butang kiraan Mathurat pagi/petang; tapis doa ikut kategori; salin teks |
| Tasbih | Ketik cincin; pilih zikir & sasaran 33/99/100; jumlah hari ini automatik |
| Kalendar | Rujuk Hijri + 5 tarikh penting; ketik hari untuk rekod solatnya |
| Zakat | Isi wang/emas/pelaburan/hutang → zakat 2.5% jika cukup nisab |
| Kiblat | Aktifkan kompas (benarkan sensor di iPhone) → pusing hingga anak panah ke atas |
| Puasa | Ketik tarikh berpuasa; lihat jumlah bulan ini & keseluruhan |
| Haid | Ketik hari haid; lihat status aktif & purata kitaran |
| Tetapan | Bahasa MY/EN, tema gelap, padam semua data (tidak boleh diundur) |

## 3. Soalan Lazim

**Perlu akaun atau internet?** Tidak. Semua rekod dalam telefon anda. Internet hanya untuk muat turun awal dan fon.

**Data hilang tukar telefon?** Ya buat masa ini (tiada sync awan). Kekalkan telefon yang sama.

**Waktu solat kawasan saya?** Dikira untuk Kuala Lumpur. Kawasan lain menyusul.

**Tersalah tanda?** Ketik butang yang sama sekali lagi untuk padam.

**Aplikasi perlahan?** Tutup tab lain, segar semula halaman. Rekod anda kekal.

## 4. Data & Privasi

Semua data (solat, haid, bookmark) tersimpan setempat di peranti (`taubat_app_v1`) — tiada pelayan, tiada akaun. Memadam aplikasi atau data pelayar memadam rekod. Tetapan → Padam semua data untuk mula semula.
