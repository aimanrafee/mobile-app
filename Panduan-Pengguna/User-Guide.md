# User Guide — Taubat.App

> **User layer** (not a developer document). Also available in-app: More → Guide.
> Language: the app is bilingual MY/EN — use the MY button in the top bar to switch.

## 1. Quick Start

1. Open the app — **Home** shows the Gregorian + Hijri date and the next-prayer countdown.
2. Tap **On time / Late / Qada** for each prayer. Tap again to clear a mistake.
3. Watch your **streak**, **this week**, and the **28-day heatmap** as gentle motivation.
4. Reopen this **Guide** anytime via More → Guide.

## 2. Every Feature

| Feature (tab) | How to use |
|---------------|------------|
| Home | Pick a day (±3 days), mark prayer status; during menstruation rows are auto-exempt |
| Quran | Search surah → open → read MY/EN → bookmark verses ★ → resume from the banner |
| Iqra' | Pick level 1–6 → tap mastered letters → % progress; mark all / reset |
| Dhikr | Tap Mathurat counters morning/evening; filter duas by category; copy text |
| Tasbih | Tap the ring; choose dhikr & 33/99/100 target; today's total is automatic |
| Calendar | Check Hijri + 5 upcoming dates; tap a day for its prayer record |
| Zakat | Fill cash/gold/investments/debts → 2.5% zakat if nisab is met |
| Qibla | Enable compass (allow sensor on iPhone) → rotate until arrow points up |
| Fasting | Tap fasted dates; see this month's & all-time totals |
| Period | Tap period days; see active status & average cycle |
| Settings | MY/EN language, dark theme, erase all data (cannot be undone) |

## 3. FAQ

**Account or internet needed?** No. All records stay on your phone. Internet is only for first load and fonts.

**Switching phones loses data?** Yes for now (no cloud sync). Keep the same phone.

**Prayer times for my area?** Calculated for Kuala Lumpur. More regions coming.

**Marked wrongly?** Tap the same button again to clear.

**App slow?** Close other tabs, refresh the page. Your records persist.

## 4. Data & Privacy

All data (prayers, period, bookmarks) is stored locally on-device (`taubat_app_v1`) — no server, no account. Deleting the app or browser data deletes records. Settings → Erase all data to start over.
